# 🌿 PlanTinder — Documentação & MVP

Plataforma desenvolvida para conectar pessoas e incentivar a adoção responsável de plantas na mesma região através da mecânica interativa de *match* ("Arraste, Curta e Adote"), integração com filtros por proximidade, comunicação direta e avaliação de doadores[cite: 1].
